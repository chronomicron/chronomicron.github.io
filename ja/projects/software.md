## ChronoVault
**状態：** 開発中

ChronoVault は、写真や動画があちこちに散らばっている人のための個人向けメディア整理ツールです。古い HDD、USB、DVD、NAS、Google Drive、Dropbox など、さまざまな場所に置かれたファイルを対象にします。

それらの場所を探索し、メディアを見つけ、一つの整理された時系列アーカイブにまとめます。日付や詳細に自信がない場合は、カメラのメタデータ、GPS、編集ソフトの履歴、あるいは画像に印字された日付の OCR など、利用できる手がかりをもとに確認・修正を助けます。

**解決したい問題**  
長年にわたり、電話・カメラ・クラウドバックアップ・忘れられた外付けディスクに写真と動画が積み重なります。すべてが一つのきれいな場所にあることは稀で、重複や雑多なエクスポート、一貫しないフォルダ構造が状況を悪化させます。ChronoVault は、手作業で全部を並べ替えなくても、日付の通った一つのアーカイブにまとめられるようにします。

## スケジュール再生対応 VLC プレーヤ
**状態：** 完了

VLC Media Player を API 経由で制御する独自アプリです。番組や映画のローカルデータベースを持ち、毎日決まった時間帯に再生します。

母のために設計したもので、テレビが自動で付き、次のような流れになります。
- 朝：クイズ・バラエティ系
- 昼：連続ドラマ（ソープオペラ）
- 夜：往年のドラマ

チャンネル操作は不要で、同じ番組が毎日同じ時間に流れます。
