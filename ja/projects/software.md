## ChronoVault
**状態：** 開発中

ChronoVault は、長年にわたって古いドライブ、USB、DVD、NAS、クラウドに散らばった写真や動画を整理するためのプロジェクトです。ばらばらのメディアを、日付順にたどれる一つのローカルアーカイブにまとめることを目指しています。

メディアを集約して日付順に整理し、確信の持てない日付を確認できるように設計しています。カメラのメタデータ、GPS、編集履歴、画像に印字された日付の OCR などを手がかりとして活用します。

**解決したい問題**  
長年にわたり、電話・カメラ・クラウドバックアップ・忘れられた外付けディスクに写真と動画が積み重なります。すべてが一つのきれいな場所にあることは稀で、重複や雑多なエクスポート、一貫しないフォルダ構造が状況を悪化させます。ChronoVault は、手作業で全部を並べ替えなくても、日付の通った一つのアーカイブにまとめられるようにします。

## スケジュール再生対応 VLC プレーヤ
**状態：** 完了

VLC Media Player を API 経由で制御する独自アプリです。番組や映画のローカルデータベースを持ち、毎日決まった時間帯に再生します。

母のために設計したもので、テレビが自動で付き、次のような流れになります。
- 朝：クイズ・バラエティ系
- 昼：連続ドラマ（ソープオペラ）
- 夜：往年のドラマ

チャンネル操作は不要で、同じ番組が毎日同じ時間に流れます。
